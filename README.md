# Personal Finance & Algorithmic Trading Platform

A full-stack personal finance application with an
automated paper trading engine.

## Planned Features

- Income and expense tracking
- Budget and savings management
- Investment portfolio dashboard
- Algorithmic trading strategies
- Paper trading through a brokerage API
- Idempotent order processing
- Crash recovery and event logging

## Tech Stack

- TypeScript
- React
- Node.js / Express
- PostgreSQL
- Docker
- Alpaca Paper Trading API

## Status

Under active development.

## Disclaimer

Trading functionality is initially paper-only.
